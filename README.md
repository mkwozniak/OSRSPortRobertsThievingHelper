# Port Roberts Thieving Helper
An OSRS Runelite Plugin which assists thieving at Port Roberts stalls.

# Features
* Highlight a Primary stall and Secondary stall to steal from.
* Show how many thieving attempts are left above a stall.
* Shows when a stall is being watched.
* Shows when a stall is safe to steal from.
* Can send an OS notification when a stall is safe to steal from.
* Can flash the screen when a stall is safe to steal from.
* Can play a sound for when a stall is being watched, and a separate sound for when it's safe to steal from.
